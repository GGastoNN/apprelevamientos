# Grupo IDEA - Relevamientos 1.2.1

## Identidad del producto

- El nombre público de la aplicación queda unificado como **Grupo IDEA - Relevamientos**.
- Los archivos exportados ahora se nombran `GrupoIDEA_Relevamientos_... .gidea`.
- Se eliminaron las referencias visibles restantes al nombre anterior del producto.
- Se mantiene internamente el `applicationId`, el nombre de la base Room y la firma/magia histórica del archivo para conservar compatibilidad de actualización y lectura de respaldos existentes.

## Compatibilidad

- No hay migración de base de datos.
- Los `.gidea` existentes siguen siendo importables.
- Versión Android: `1.2.1` / `versionCode 12`.
